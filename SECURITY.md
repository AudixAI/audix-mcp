# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's
[GitHub security advisory form](https://github.com/AudixAI/audix-mcp/security/advisories/new).
Do not open a public issue for an unpatched vulnerability and do not include
credentials, access tokens, private source code, or other sensitive data in a
report.

Include the affected `@audix/mcp` version, the relevant MCP tool or workflow,
reproduction steps, impact, and any proposed mitigation. Audix will acknowledge
the report, validate it, and coordinate remediation and disclosure with the
reporter.

## Supported versions

Until a broader support policy is announced, only the latest published version
of `@audix/mcp` receives security fixes.
